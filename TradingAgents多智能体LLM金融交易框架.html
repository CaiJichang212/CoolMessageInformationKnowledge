🚀 TradingAgents 是一个模拟真实交易公司运作模式的多智能体交易框架。通过部署由大语言模型驱动的专业智能体——从基本面分析师、情绪分析师、技术分析师，到交易员和风险管理团队，平台能够协同评估市场状况并制定交易决策。

我们的框架将复杂交易任务分解为专业角色。这种设计确保系统采用稳健、可扩展的方法进行市场分析和决策制定。

⚠️ TradingAgents 框架仅供研究用途。交易表现可能因多种因素而异，本框架不作为财务、投资或交易建议。

01 分析师团队

📍 基本面分析师

评估公司财务和业绩指标，识别内在价值和潜在风险信号
📍 情绪分析师

运用情绪评分算法分析社交媒体和公众情绪，研判短期市场情绪
📍 新闻分析师

监测全球新闻和宏观经济指标，解读事件对市场状况的影响
📍 技术分析师

运用MACD、RSI等技术指标识别交易模式并预测价格走势

02 研究团队

📍 多头与空头研究员

由多头和空头研究员组成，他们会对分析师团队提供的见解进行批判性评估。通过结构化辩论，权衡潜在收益与固有风险。

03 交易员代理

📍 交易决策

整合分析师和研究员的报告，做出明智的交易决策。基于全面的市场洞察，决定交易时机和规模。

04 风险管理与投资组合经理

📍 风险监控与投资组合管理

通过评估市场波动性、流动性及其他风险因素，持续监控投资组合风险。投资组合经理审批交易提案，若获批准，订单将发送至模拟交易所执行。

05 安装与命令行界面

安装步骤：

  • 克隆仓库：
    git clone https://github.com/TauricResearch/TradingAgents.git
  • 创建虚拟环境：
    conda create -n tradingagents python=3.13
  • 安装依赖：
    pip install -r requirements.txt

配置 API 密钥（支持 OpenAI、Google、Anthropic、xAI、OpenRouter、Alpha Vantage）：

  • export OPENAI_API_KEY=...
  • export GOOGLE_API_KEY=...
  • export ANTHROPIC_API_KEY=...

运行 CLI：

  • python -m cli.main

06 TradingAgents 包

🏗️ 技术实现： 使用 LangGraph 构建，支持多个 LLM 提供商

✨ 支持模型： OpenAI、Google、Anthropic、xAI、OpenRouter 和 Ollama

Python 调用示例：

from tradingagents.graph.trading_graph import TradingAgentsGraph from tradingagents.default_config import DEFAULT_CONFIG ta = TradingAgentsGraph(debug=True, config=DEFAULT_CONFIG.copy()) # forward propagate _, decision = ta.propagate("NVDA", "2026-01-15") print(decision)

配置选项示例：

config = DEFAULT_CONFIG.copy() config["llm_provider"] = "openai" config["deep_think_llm"] = "gpt-5.2" config["quick_think_llm"] = "gpt-5-mini" config["max_debate_rounds"] = 2

✓ 总结

TradingAgents 通过多智能体协作模拟真实交易公司运作，从分析师研究到风险管理，形成完整的自动化交易决策流程。该框架仅供研究使用，不构成投资建议。
